# MERN AI Habit Management Application

A full-stack habit tracking and management web application built as a final project for the PNY course. This application helps users build better daily habits, maintain streaks, and receive personalized AI-powered insights.

---

## Features
* **User Authentication:** Secure registration and login functionality.
* **Habit Tracking:** Create, update, and monitor daily/weekly habit logs.
* **Streak Management:** Track consistency using automated date utilities.
* **AI Insights:** Integrated with Google Gemini API (`gemini-2.0-flash`) to generate personalized weekly habit suggestions and progress analysis.

---

## Tech Stack
* **Frontend:** React / HTML / CSS / JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB & Mongoose
* **AI Integration:** `@google/genai` (Google Gemini API)
